Experiment Report: UCB Routing

Experiment ID: ucb_ingolstadt_custom_config1

1. Algorithm Details

1.1 Model & Origin

The core algorithm is an independent Tabular Q-Learning model utilizing the Upper Confidence Bound (UCB) action-selection strategy for Multi-Armed Bandits. The foundational logic for this implementation was ported directly from the legacy research scripts located in:

  • AVs_marginal_cost/saint_arnoult_network/ucb_saint_arnoult.py
  • AVs_marginal_cost/two_route_net/ucb.py

1.2 Algorithm Mechanics

Unlike standard epsilon-greedy exploration, the UCB algorithm treats the routing choice as a Contextual Multi-Armed Bandit problem. It balances exploitation (choosing historically fast routes) with exploration (testing rarely used routes) by mathematically calculating an upper confidence bound for each route option. It operates as follows:

  • State Space: The continuous observation space (previous_agents_plus_start_time) is discretized into bins so the agent can look up discrete states in a Q-Table.
  • Action Selection: For a given state s, the agent selects action (route) a that maximizes:
    Q(s, a) + β * √(2 * ln(N(s)) / N(s, a))
    Where Q(s, a) is the estimated reward, N(s) is the total visits to the state, N(s, a) is the visits to that specific state-action pair, and β (Beta) controls the exploration magnitude.
  • Q-Table Update: After a vehicle completes its route, the agent updates its Q-table using a constant learning rate (α):
    Q(s,a) ← (1 - α) * Q(s,a) + α * Reward
  • Reward Structure: The reward signal is the negative travel time (-travel_time). Crucially, this implementation utilizes independent learners, meaning each CAV optimizes its own route selfishly without shared fleet memory.
