Experiment Report: Sweep Bandit REINFORCE Routing

Experiment ID: sweep_bandit/lr_3e-4_ent_0.01_temp_0.5_seed_42

1. Algorithm Details

1.1 Model & Origin

The core algorithm is an independent Bandit REINFORCE policy gradient model utilizing a PyTorch Multi-Layer Perceptron (MLP) architecture. It was developed directly in this repository (scripts/bandit_reinforce.py) to replace the legacy UCB algorithm with a differentiable deep learning approach.

1.2 Algorithm Mechanics

Unlike UCB which uses deterministic bounds, Bandit REINFORCE maintains a stochastic policy (a probability distribution) over all possible routes. It operates as follows:

  • State Space: The continuous observation space (previous_agents_plus_start_time) is fed directly into a multi-layer Neural Network without arbitrary discretization.
  • Action Selection: The neural network outputs logits (scores) for each route. These logits are scaled by a Temperature parameter and converted into probabilities using a Softmax function. The agent then dynamically samples a route from this probability distribution.
  • Exploration via Entropy: To prevent premature convergence to sub-optimal routes, an Entropy Bonus is mathematically added to the objective function, forcing the agent to maintain a minimum level of randomness in its early route choices.
  • Network Update: After completing a route, the agent calculates the log-probability of the chosen route and multiplies it by the advantage (Reward - Baseline). The network weights are updated using gradient ascent (the REINFORCE theorem) scaled by the Learning Rate.
  • Reward Structure: The reward signal is the negative travel time (-travel_time), encouraging the network to strictly increase the probability of choosing faster routes.
