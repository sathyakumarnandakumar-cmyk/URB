# `analysis/` Module Reference

This directory contains the `metrics.py` script, which is responsible for post-processing raw experiment outputs into aggregated scalar and vector metrics. It acts as the analytics engine for the URB framework, directly extracting data from XML (SUMO) and CSV (RouteRL) files.

## Dependencies & Imports

```python
import glob
import os
import sys
import argparse
import json
import xml.etree.ElementTree as ET

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
from tqdm import tqdm
```
- **Standard Library:** Uses `xml.etree.ElementTree` extensively for parsing SUMO XML logs, and `glob`/`os` for directory traversal.
- **Third-Party:** Uses `pandas` to flatten and align agent data over episodes, `numpy` for missing value handling, and `matplotlib` for basic metric plotting.

---

## Data Flow & Architecture

1. **Discovery:** The script locates the target experiment folder in `results/` using the `--id` argument.
2. **Configuration Loading:** Reads `exp_config.json` to extract simulation boundaries (e.g., `human_learning_episodes`, `experience_collecting_episodes`, `training_eps`).
3. **Data Loading (Per Episode):** Iterates over every valid episode. For each episode, it calls `load_detailed_SUMO`, `load_general_SUMO`, and `load_routeRL`.
4. **Alignment & Flattening:** Because multi-agent datasets natively take a 3D shape (Episodes × Agents × Features), `metrics.py` squashes this into a 2D `pd.DataFrame`. A single row represents an entire episode. Agent-specific columns are prefixed with `agent_<id>_` (e.g., `agent_10_duration`).
5. **Phase Slicing:** The combined DataFrame is sliced into distinct temporal phases: `before_mutation`, `after_mutation`, `training_frames`, and `testing_frames`.
6. **Metric Extraction:** Computes final system metrics like CAV advantage, training cost, and instability based on ID filtering.

## Deep Function Reference: `metrics.py`

### 1. `load_detailed_SUMO(file: str) -> pd.DataFrame`
**Purpose:** Parses the `detailed_sumo_stats_X.xml` generated by SUMO which logs `tripinfo` for every vehicle that reaches its destination.

**Arguments:**
- `file (str)`: Absolute path to the XML file.

**Returns:**
- A single-row `pd.DataFrame` containing flattened trip information for all agents.

**Internal Logic & Code Snippet:**
The XML parser extracts the raw attributes for every `<tripinfo>` element. 
```python
tree = ET.parse(file)
root = tree.getroot()
data = [trip.attrib for trip in root.findall("tripinfo")]
df = pd.DataFrame(data)
```
It retains specific columns (`id`, `depart`, `duration`, `timeLoss`, `vType`). The data is then cast to numeric types and passed to `flatten_by_id()` which pivots the dataframe so that `id` becomes a prefix for the remaining columns.

### 2. `flatten_by_id(df: pd.DataFrame) -> pd.DataFrame`
**Purpose:** Converts a multi-row DataFrame (where rows = agents) into a single-row DataFrame (where columns = `agent_{id}_{feature}`).

**Arguments:**
- `df (pd.DataFrame)`: DataFrame requiring flattening. Must have an `"id"` column.

**Returns:**
- Single row `pd.DataFrame`.

**Internal Logic & Code Snippet:**
```python
df_indexed = df.set_index("id")
s = df_indexed.stack()
# Maps multi-index (id, feature) to 'agent_id_feature'
new_names = s.index.map(lambda idx: f"agent_{idx[0]}_{idx[1]}")
flattened_df = pd.DataFrame([s.values], columns=new_names)
```
This enables the framework to easily concatenate episodes vertically using `pd.concat`, producing a clean, aligned table.

### 3. `slice_episodes(df: pd.DataFrame, config: dict) -> dict`
**Purpose:** Segments the complete simulation history into analysis phases.

**Arguments:**
- `df (pd.DataFrame)`: The vertically concatenated dataframe containing all episodes.
- `config (dict)`: The parsed `exp_config.json` containing phase lengths.

**Returns:**
- A dictionary containing four DataFrames: `before_mutation`, `after_mutation`, `training_frames`, and `testing_frames`.

**Internal Logic:**
Calculates logical phase boundaries using the configuration:
```python
hl_episodes = int(config["human_learning_episodes"])
experience_collecting_eps = int(config["experience_collecting_episodes"])
training_eps = int(config["training_eps"])

trainphase_start_episode = hl_episodes + experience_collecting_eps + 1
testphase_start_episode = hl_episodes + experience_collecting_eps + training_eps + 1
```
It uses pandas boolean indexing (e.g., `df[(df["episode"] >= trainphase_start_episode)]`) to generate and return `.copy()` slices.

### 4. `extract_metrics(path, config, verbose=False)`
**Purpose:** Calculates the final scalar indicators evaluating the routing performance.

**Arguments:**
- `path (str)`: Path to the combined CSV file.
- `config (dict)`: Experiment configuration.

**Returns:**
- `metrics_df (pd.DataFrame)`: Single-row dataframe containing scalar variables.
- `vector_metrics_df (pd.DataFrame)`: Multi-row dataframe containing episode-level tracking.

**Internal Logic:**
- First calls `slice_episodes`.
- Identifies agent groupings using `get_type_ids(df, "AV")` and `"Human"`.
- Calculates baseline averages. E.g., `t_pre` (average system travel time before AV introduction).
- Computes highly specialized metrics like `Cost of Learning`:
  ```python
  def get_cost_of_learning(df_slice, ids):
      cols = [f"agent_{id}_duration" for id in ids if f"agent_{id}_duration" in df_slice.columns]
      durations = df_slice[cols]
      cost_series = durations.max() - durations.min()
      return cost_series.mean()
  ```
- Evaluates the final win-rate by checking if $t_{CAV} < t_{pre}$.
- Converts all duration statistics (measured in seconds natively by SUMO) to minutes, and speeds to km/h, before formatting them into a dictionary for output.
